# Game Design — Rong Shen / Singlong404

**AA_建筑设计沈工 · Rong Shen (Singlong404)**

- [Mirror Trip 正式试玩版 / Current demo](https://singlong404.github.io/Game_design_public/mirror-trip/)
- [Mirror Trip 源码 / Source code](mirror-trip-source/)
- [Mirror Trip 灰盒版 / Greybox prototype](https://singlong404.github.io/Game_design_public/mirror-trip-greybox/)

Both demos render at 1920 × 1080 and fit the browser window. Desktop Chrome / Edge and keyboard + mouse are recommended.

This repository contains playable builds and a [public game source snapshot](mirror-trip-source/) for Game Off 2026 (theme: SHIFT). The source includes gameplay scripts and custom shaders; production artwork, scene assets and the complete authoring project remain private. The snapshot is readable source, not a self-contained rebuildable project or an open-source license grant. See [COPYRIGHT.txt](COPYRIGHT.txt); third-party license terms remain in effect.

The greybox was migrated from `Singlong404/mirror-trip-web`, commit `75ff7c2e1f2b80e9cdb3a865d562455aeda479bf`. Its original build files are preserved.
